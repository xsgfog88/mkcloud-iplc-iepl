## 两条主力线路的实测数据怎么看

第三方博主在 2023 年 11 月底至 12 月初对广港 IEPL 和沪日 IPLC 的 500GB 档做过完整测试，两份报告拼在一起，能看出这条产品线的基本盘。共同点先说：两个出口的单线程带宽都在 130Mbps 上下，磁盘 I/O 均值 280–300MB/s，虚拟化为 KVM，内核开启 BBR，配置给得不算抠。

差异在方向性上。

**沪日 IPLC（东京出口）**：入口走上海电信，出口是东京 BGP（Nearoute）。东京本地节点延迟 25ms 左右，Linode 东京 132Mbps、Softlayer 东京 130Mbps；到台湾 Hinet 55ms/119Mbps，到首尔 58ms/125Mbps。美西方向 90Mbps/134ms，正常水平。欧洲方向衰减明显，多数节点只有 10–25Mbps，阿姆斯特丹的 68Mbps 算个例外。还有个细节：新加坡方向当时只测出 0.92Mbps，即便是个例，也说明东南亚方向不是这条线的强项。

**广港 IEPL（香港出口）**：入口是 UCloud 广州 BGP，出口 Nearoute 香港。香港本地延迟只有 5ms 上下，Leaseweb 和 xTom 的香港节点都跑到 131–135Mbps；到台湾 26ms，到新加坡 38ms/130Mbps。跟沪日最大的区别在国际方向：美西 96–104Mbps，欧洲伦敦、法兰克福、阿姆斯特丹都有 86–91Mbps，比沪日的欧洲表现好一截。

## 独享 IP 到底值不值：看两组 IP 质量数据

Mkcloud 把“入口出口独享 IP”当核心卖点，实测的 IP 质量数据能告诉你这个卖点实际意味着什么。

沪日出口的东京 IP（AS51847，Nearoute）是 IDC 机房 IP，不同数据库给的画像差别很大：机器学习风控库里它显示 VPN 概率 64%、Proxy 概率 100%、可信度只有 12%；但 scamalytics 和 IPQualityScore 两家的欺诈评分都给了 0/100 的低分。广港出口（AS147293）情况类似，机器学习库里 Proxy 概率 100%，IPQualityScore 给了 65/100 的中等分并标记为 VPN/Proxy。

翻译成人话：独享 IP 没有前任住客留下的“脏历史”，欺诈评分干净，日常使用没问题；但它们本质仍是机房 IP，在严格风控的服务那里“看起来像代理”。拿它注册对 IP 敏感的金融、社媒账号，可能多几步验证。对绝大多数场景，这不构成障碍。

两个实操提醒。其一，广港出口带原生 IPv6，沪日没有——用途依赖 IPv6 的话，直接排除沪日。其二，两个出口 IP 的 SSH 爆破风险值在 36%–41%，公网扫描很勤，拿到出口机器后第一时间改 SSH 端口、关掉密码登录。

## 实名、退款和流媒体：条款里藏着的三件事

这三条限制都来自商家的公开条款和第三方整理，买之前过一遍：

1. **流媒体不保证解锁**。2023 年 12 月沪日出口实测能解锁 Disney+、Netflix 和 ChatGPT，但条款里商家明确不承诺流媒体解锁。当时的解锁状态随时可能变，别把它当流媒体专线买。
2. **退款仅限证实质量问题**。“用着不习惯”不在退款范围内。
3. **IPLC/IEPL 要国内手机号实名**，确认你的号码能走完认证流程再付款。

退款条件苛刻，对应的做法是把证据工作做在前面。下单后 48 小时内建议完成三件事：早中晚不同时段 ping 出口 IP、记录延迟波动；用 traceroute 类工具查回程路由，确认走的是专线而非绕公网；跑一次真实带宽测速，对照套餐标称值。这些数据留着，真遇到质量纠纷时，比任何解释都管用。多数评测文章贴了数据，但很少告诉你数据要这么用。
